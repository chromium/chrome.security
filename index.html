Chrome Security's mission is to make it safe to click on links.

We aim to fulfil this mission through our focus on counter-abuse, agentic security, network security, web platform security standards, exploit defense, and vulnerability detection and response.

We also provide the building blocks so that all of Chrome is built with security front of mind.
